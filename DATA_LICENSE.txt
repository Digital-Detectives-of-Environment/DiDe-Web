1. WHAT THE DATA IS
--------------------------------------------------------------------------------

DiDe is a citizen-science platform. Volunteers ("Contributors") report
environmental observations - for example litter, damaged infrastructure or
other environmental problems - by marking a location on a map, choosing an
event type, adding a short description and, optionally, photos, videos and
the direction they were facing. Other users can "agree" with a report to
confirm it. Contributors earn points for useful activity, and moderators
("Supervisors") manage event types and can close reports.

The data is therefore CROWD-SOURCED. It is collected by members of the public,
it is not an official survey, and it has NOT been verified as accurate,
complete or current (see Section 8).

ANNEX A - FIELDS IN THE EXPORT FILES (events.geojson)
--------------------------------------------------------------------------------

OPEN DATA export (no account required):

  event_id      Unique number of the report on the Platform.
  latitude      Latitude of the reported location (WGS 84, EPSG:4326).
  longitude     Longitude of the reported location (WGS 84, EPSG:4326).
  event_type    Name of the event type (category) of the report.
  description   Free-text description written by the Contributor.
  created_at    Date and time the report was created (ISO 8601, UTC).
  photo_urls    File names of the report's photos, found in the "photos/"
                folder of the archive.
  num_agrees    Number of users who currently agree with (confirm) the
                report.
  direction     Direction the Contributor was facing, in degrees clockwise
                from north (0 = N, 90 = E, 180 = S, 270 = W); empty if
                unknown.

  Only ACTIVE reports of PUBLIC event types are included.

PERSONAL export ("Download my data", only your own reports) additionally
contains:

  active               true if the report is still open, false if closed.
  deactivated_by_name  Who closed the report (if closed).
  deactivated_at       When the report was closed (if closed).
  video_urls           File names of the report's videos ("videos/" folder).
  last_agreed_date     Date and time of the most recent agreement (or of
                       creation).
  <area key columns>   Only if the Platform uses an aggregation layer: the
                       identifier(s) of the area (for example a grid cell or
                       district) that contains the report.

The geometry of each feature is a GeoJSON Point using the same coordinates.
